# Fortune Cookie for the Liquidated Trader

A single-line fortune cookie for the crypto trader who just got liquidated — small, oracular, and gently funny about the loss. One fortune, one breath, one sting that lands warm, not cruel.

## Run

```bash
node main.ts
```

`main.ts` reads `line.txt` in the same directory, validates it (1–160 characters, a single line, at most 20 words), and writes the exact same bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is not set), with no trailing newline.
